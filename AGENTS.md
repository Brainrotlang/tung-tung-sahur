# AGENTS.md

TUNG TUNG TUNG SAHUR: RUN is an endless runner written **entirely in
[Brainrot](https://github.com/Brainrotlang/brainrot)** and rendered through the
`rayrot` raylib binding (`#cooked <raylib>`). The frame loop, entity pools,
spawner, collision, scoring, and both bosses are `.brainrot`; art is PNG atlases
generated by `tools/`.

## The one rule: zero C here

**This repository contains no C, and adds none.** Anything the game needs that
Brainrot or raylib can't yet express is implemented *upstream* in
[`Brainrotlang/brainrot`](https://github.com/Brainrotlang/brainrot) (see the
running list in `DESIGN.md` §15), then consumed here. If a change would require
new C in this repo, it's the wrong repo — open it upstream instead.

## Setup / Build / Test

The game runs on the `brainrot` interpreter plus the `rayrot` module; clone
[`brainrot`](https://github.com/Brainrotlang/brainrot) **next to this repo** and
build both. `make` probes the interpreter and refuses one that's too old
(**>= v0.3.0** for the language features the game uses; the release bundles pin
**v0.5.1**, the first with native Windows):

```bash
git clone https://github.com/Brainrotlang/brainrot ../brainrot
make -C ../brainrot            # the interpreter
make -C ../brainrot rayrot     # the raylib binding (needs raylib installed)
```

Then, from this repo:

```bash
make play         # build rayrot + run the game (needs raylib + a display)
make test         # unit + headless golden-file tests (NO raylib, NO display)
make lint-native  # type-check every real rl_* call without a window
make check-atlases# the generated atlases still match tune.brainrot (needs Python+Pillow)
make bless        # regenerate golden files (read the diff before committing!)
```

If your `brainrot` checkout is elsewhere: `make play BRAINROT_DIR=/path/to/brainrot`.
raylib setup per OS is documented once, upstream, in
[`brainrot/docs/rayrot.md`](https://github.com/Brainrotlang/brainrot/blob/main/docs/rayrot.md).

## Project structure

- `src/*.brainrot` — the game. `main.brainrot` holds the frame loop's *shape*
  (state machine, pools, step order); `sim.brainrot` does each step's work;
  `tune.brainrot` is every tuning constant as accessor functions; `draw`/
  `platform` are the raylib seam; `math`/`collide`/`curve` are pure helpers.
- `test/` — `unit_*.brainrot` (pure functions), the fakes (`platform_fake`,
  `draw_fake`), and `expected/` golden files.
- `assets/` — source frames per subject + the generated atlases.
- `tools/` — `process_sprites.py` (atlas generation) and `check_atlases.py`;
  Python deps in `tools/requirements.txt`.
- `DESIGN.md` — the **single source of truth** for tuning, the speed curve,
  boss phases, architecture, and the upstream dependency list. Cite its section
  when you change behavior.

## Testing requirements

- Tests need **neither raylib nor a display** — they swap `draw.brainrot` and
  `platform.brainrot` for the fakes in `test/`. Output is compared against
  golden files in `test/expected/`.
- New or changed simulation ⇒ add/extend a `test/unit_*.brainrot`, run
  `make bless`, and **read the golden diff before committing** — a moved golden
  is either the point of your change or a bug you just wrote.
- `make test` and `make lint-native` must both pass. `lint-native` is what
  catches a wrong `rl_*` argument count (the fakes hide the real calls), so run
  it whenever you touch `draw.brainrot`/`platform.brainrot`.
- Changing sprite art or its size ⇒ regenerate with `tools/process_sprites.py`
  and run `make check-atlases`.

## Boundaries

- **Never**: add or vendor C in this repo; edit `src/.headless.gen.brainrot`
  (it is GENERATED from `src/main.brainrot` by `make` — gitignored); commit a
  `make bless` without reading its diff.
- **Always**: keep the simulation/drawing split intact (the headless harness
  depends on it — sim never draws or plays audio); keep `tune.brainrot` the one
  place tuning constants live; run `make test` + `make lint-native` before
  calling a change done.
- **Upstream, not here**: any interpreter/`rayrot` capability gap — file it in
  `Brainrotlang/brainrot` and note it in `DESIGN.md` §15.
